📘 Assignment: Logic Rules

This project demonstrates how propositional logic can support automated shopping recommendations.

Rule 1: Budget constraint

B = (Product price ≤ User budget)

Rule 2: Category and search match

C = (Category matches) ∧ (Search matches)

Rule 3: Product quality or discount

Q = R ∨ D
A product qualifies when its rating meets the selected threshold or its discount meets the selected threshold.

Final recommendation rule

P = B ∧ C ∧ Q

The system recommends a product when all mandatory conditions are true and the selected quality rule is satisfied. The priority selector can change Q to R, D, or R ∧ D.
